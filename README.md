## Featured Projects

### WebPyS

**Web Passive Scanner & Reconnaissance Tool**

WebPyS is a Python-based security reconnaissance tool designed to automate passive web security analysis.

**Features include:**

* HTTP security header analysis
* SSL/TLS certificate inspection
* Certificate expiry checking
* Subdomain enumeration
* WAF fingerprinting
* Basic port analysis
* Multithreaded scanning
* HTML/XML report generation

The project was designed to make repetitive reconnaissance tasks faster and easier for security researchers.
